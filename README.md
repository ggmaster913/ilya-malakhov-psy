# Сайт-визитка: Илья Малахов, психолог (КПТ)

Статический сайт без сборки: `index.html` (главная), `kpt.html` (страница о методе) + `assets/`.

## Как открыть

Сайт можно открыть двойным кликом по `index.html`, но надёжнее — через локальный сервер
(так же, как он будет работать на хостинге):

- **двойной клик по `start.command`** — откроется браузер с сайтом;
- или в Терминале из этой папки: `python3 -m http.server 8080` → http://localhost:8080

На хостинге (Netlify, GitHub Pages, любой веб-сервер) всё работает как есть.

## Что заменить

Данные взяты из профиля https://www.b17.ru/malakhov_ilya/ (образование, направления, цены, АКПП).

- `assets/img/portrait-square.webp` — фото на первом экране (квадрат, 1100×1100).
- Почта: `hello@example.com` (Telegram уже настоящий — @meraxes9000).
- Отзывы — примеры оформления (имена и запросы вымышленные). Впишите реальные и удалите строку с классом `reviews__notice`.
- В блоке «Образование» строка «Курсы» — без организации и года: впишите, где и когда пройден курс КПТ.
- Заявки уходят через FormSubmit на mushruntie@mail.ru. Первую заявку нужно отправить самому и подтвердить
  письмо от FormSubmit, после этого адрес в `action` можно заменить на выданную ими ссылку вида
  `https://formsubmit.co/ajax/<хеш>`, чтобы почта не светилась в коде.
